## Objetivo

Desarrollar programas utilizando clases, objetos y métodos, lo cual permite disminuir errores y reutilizar el código.

## Ejercicios

| Carpeta | Tema | Concepto aplicado |
|---|---|---|
| `ejercicio1-libro-autor` | Libro y Autor | Objeto como atributo |
| `ejercicio2-rectangulo` | Rectángulo | Métodos con distintos tipos de retorno (`double`, `boolean`, `String`, `void`) |
| `ejercicio3-producto-venta` | Producto y Venta | Objeto como parámetro |
| `ejercicio4-transferencias` | Transferencias entre cuentas | Objeto como parámetro y validación de fondos |
| `ejercicio5-biblioteca` | Biblioteca (Usuario, Libro, Préstamo) | Colaboración entre clases |

## Cómo ejecutar

Requisitos: JDK 17 o superior.

```bash
cd ejercicio1-libro-autor
javac *.java
java Main
```

Repite los mismos pasos en la carpeta de cada ejercicio. Cada carpeta es independiente, por lo que los nombres de clase (`Libro`, `Main`) pueden repetirse entre ejercicios.
